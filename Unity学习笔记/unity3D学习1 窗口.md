# unity3D学习 窗口

## 1.常用窗口

### Scene  场景编辑窗口

自由漫游场景并对场景进行修改

#### 快捷键：

+ Q（鼠标右键）：移动场景

+ W：移动选中”物体“

  ![image-20220306234426416](https://gitee.com/yimuzhexi/pic/raw/master/img/image-20220306234426416.png)

+ E：在平面内进行相对单向旋转（一次只能朝一个方向旋转）

  ![image-20220306234458768](https://gitee.com/yimuzhexi/pic/raw/master/img/image-20220306234458768.png)

+ R：改变”物体“大小（单方向）

![image-20220306234643318](https://gitee.com/yimuzhexi/pic/raw/master/img/image-20220306234643318.png)

+ T：改变”物体“大小（多方向）

![image-20220306234802114](https://gitee.com/yimuzhexi/pic/raw/master/img/image-20220306234802114.png)

+ Y：移动、旋转、改变物体大小（单方向）

  ![image-20220306234918064](https://gitee.com/yimuzhexi/pic/raw/master/img/image-20220306234918064.png)

### Game  游戏运行窗口

#### 各个键的作用

![image-20220306235934834](https://gitee.com/yimuzhexi/pic/raw/master/img/image-20220306235934834.png)

+ 上方播放键：点击一次运行游戏，可在窗口中看见游戏运行的状态<br>再次点击停止运行
+ 暂停键：点击暂停游戏的运行
+ 第三个键：点击可看见下一帧运行情况
+ ==注意：在运行时对场景的所有编辑在运行结束后均将恢复原样==

#### 窗口大小调节

![image-20220307000244328](https://gitee.com/yimuzhexi/pic/raw/master/img/image-20220307000244328.png)

+ Free Aspect：全屏显示
+ Maximize On Play：游戏下次运行将全屏播放
+ Stats：控制是否显示游戏运行时的各种参数
+ Gizmos：控制是否显示各种标记，如光源、粒子等

### Hierarchy  场景物体列表窗口

在unity中所有物体都以列表的方式展示在Hierarchy窗口中，双击会将画面自动移动到该物体位置。

![image-20220307225806762](https://gitee.com/yimuzhexi/pic/raw/master/img/image-20220307225806762.png)

### Project  项目资源列表窗口

![image-20220307230025100](https://gitee.com/yimuzhexi/pic/raw/master/img/image-20220307230025100.png)

在unity中，所有项目资源都可以通过Project项目资源窗口查看，它所显示的类容与文件夹中显示的类容几乎一致，唯一区别是文件夹中会显示出由unity自动生成的meta文件

==注意：移动文件不能在文件夹中进行，否则unity会报错，请在unity编辑器里面操作==

![image-20220307230455013](https://gitee.com/yimuzhexi/pic/raw/master/img/image-20220307230455013.png)

Favorites下面可以查找特定类型的资源

![image-20220307230734898](https://gitee.com/yimuzhexi/pic/raw/master/img/image-20220307230734898.png)

### Inspector  属性编辑列表窗口

![image-20220307230846053](https://gitee.com/yimuzhexi/pic/raw/master/img/image-20220307230846053.png)

unity中的物体以及相应的资源，都可以在Inspector中进行相应的编辑，不同属性的资源有不同属性的编辑类容。
