# Blender风格化动画

## Blender基础操作

### Blender基础快捷键

#### 移动场景

| 快捷键              | 作用          |
| ------------------- | ------------- |
| `鼠标中键拖动`      | 旋转场景      |
| `Shift + 鼠标中键`` | 平移场景      |
| `滚轮`              | 放大/缩小场景 |

#### 物体操作

| 快捷键                       | 作用                     |
| ---------------------------- | ------------------------ |
| `鼠标左键``                  | 确认操作                 |
| `鼠标右键`                   | 取消操作                 |
| `G`                          | 移动物体                 |
| `R`                          | 以屏幕平面为基准旋转物体 |
| `R + R`                      | 自由旋转物体             |
| `S`                          | 缩放物体                 |
| `任意操作键 + X/Y/Z`         | 仅沿着X/Y/Z轴操作        |
| `任意操作键 + Shift + X/Y/Z` | 排除X/Y/Z轴进行操作      |
