### Blender功能模块介绍

| Blender界面    | 翻译     | 功能                         |
| -------------- | -------- | ---------------------------- |
| Layout         | 布局     | 摆放检查模型                 |
| Modeling       | 建模     | 编辑模型                     |
| Sculpting      | 雕刻     | 模型雕刻                     |
| UV Editing     | UV编辑   | 模型UV展开，便于绘制贴图     |
| Texture Paint  | 纹理绘制 | 贴图绘制                     |
| Shading        | 着色     | 材质编辑器                   |
| Animation      | 动画     | 制作动画                     |
| Rendering      | 渲染     | 将模型渲染为平面图           |
| Compositing    | 合成     | 图片后期处理                 |
| Geometry Nodes | 几何节点 | 参数化建模                   |
| Scripting      | 脚本     | 使用Python语言添加自定义脚本 |

### 坐标轴（轴向）

#### 轴向方向

| 轴向方向   | 作用                                                 |
| :--------- | ---------------------------------------------------- |
| 全局坐标轴 | 将移动、旋转、缩放等的基准坐标轴设为全局坐标轴       |
| 局部坐标轴 | 将移动、旋转、缩放等的基准坐标轴设为物品对象坐标轴   |
| 法向坐标轴 | 将移动、旋转、缩放等的基准坐标轴设为所选面朝向的位置 |
| 游标       | 将移动、旋转、缩放等的基准坐标轴设为游标所在坐标轴   |

#### 轴向位置

| 轴向位置   | 作用                                           |
| ---------- | ---------------------------------------------- |
| 边界框中心 | 将坐标轴原点设置为所选物体边界框中心           |
| 游标       | 将坐标轴原点设置为游标所处位置                 |
| 各自原点   | 将坐标轴原点设置为每个物体自身的原点，互不干扰 |
| 活动元素   | 将坐标轴原点设置为最后选中的物体原点           |

#### 生成组

生成组修改器用于快速生成物体，可以按照设定对物体对象进行修改，具体包含的常用功能如下：

| 修改器名称 | 功能                                                         |
| ---------- | ------------------------------------------------------------ |
| 阵列       | 按照设置好的参数对模型将进行批量复制<br>（1）适配类型：可以简单设置生成数量及规律；<br>（2）相对偏移：下一个复制的物体相对于上一个物体的偏移位置；<br>（3）恒定偏移：每一个物体固定的偏移量，会与固定偏移做加法运算一起偏移；<br>（4）物体偏移：根据选中的一个物体来计算偏移量，适合制作一些特殊效果；<br>（5）合并：如果启用的话，在指定的距离内，每个副本中的顶点会和下一个副本中的顶点合并。 |
| 倒角       | 可以快速对物体所有边进行倒角，并且可以随时进行修改（在进行其他操作时需要应用修改）。 |
| 布尔       | 实现可修改的布尔效果。                                       |
| 建形       | 实现物体一点点出现的效果。                                   |
| 精简       | 可以减少模型面数，模型会不可避免发生形变。                   |
| 拆边       | 将模型每一条边进行拆分，成为单个独立的面。                   |
| 遮罩       | 将未选中的顶点进行隐藏，可以随时显示或取消显示，便于观察与修改。 |
| 镜像       | 生成镜像对象，并且可以对模型做镜像修改。                     |
| 多级精度   | 常用于雕刻模式下面数不够使增加面数进行雕刻。                 |
| 重构网格   | 根据选择的网格类型，对网格进行重构。                         |
| 螺旋       | 设置物体绕某一轴心对象将进行不同方式的旋转。                 |
| 蒙皮       | 根据点线生成物体对象，适合制作树枝等修长分叉物体，可以一键生成骨骼。 |
| 实体化     | 类似于挤出，可以为面快速增加厚度。                           |
| 表面细分   | 将面进行细分并平滑。                                         |
| 三角化     | 将各个面三角化，可以按照设置的参数将进行自定义三角化。       |
| 焊接       | 实现一定距离内的点自动焊接到一起。                           |
| 线框       | 将模型按照布线进行线框化，适合制作网格类似物。               |

### 曲线

#### 编辑模式下的曲线操作

| 操作       | 功能                                                         |
| ---------- | ------------------------------------------------------------ |
| **自由笔** | 需要长按鼠标左键绘制，可以自定义进行曲线绘画，并根据弯曲位置自动生成弯曲点。 |
| **曲线笔** | （1）可以直接在场景中单击绘制点，将会自动按照顺序将点连成线；<br>（2）按住`Ctrl`可以从已有的曲线中添加一个点。 |
| **挤出**   | 对选中点进行挤出，并自动连接到线上。                         |
| **半径**   | 当曲线有倒角深度时，可以选中点修改该部分的半径大小。         |
| **倾斜**   | `Ctrl T`，可以将表面网格进行扭曲，实现更多风格化编辑。       |
| **切变**   | 可以详细的对曲线进行弯曲调整，类似于旋转。                   |
| **随机**   | 对曲线调整时可以实现随机化。                                 |

#### 曲线顶点类型

可通过快捷键`V`进行调整。

| 类型     | 描述                                                 |
| -------- | ---------------------------------------------------- |
| **自动** | 调整曲线时手柄自动改变朝向                           |
| **矢量** | 手柄出现夹角，可以制作尖角                           |
| **对齐** | 手柄保持180°夹角，并且同时进行移动                   |
| **自由** | 手柄可自由移动，与矢量类似，不同的是不会自动改变夹角 |
