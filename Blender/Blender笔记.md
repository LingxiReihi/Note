#### 1.挤出`E`

挤出操作快捷键是`E`，它实际执行了==挤出和移动两个操作==，因此右键只会取消移动操作，想要取消挤出操作需要使用`Ctrl Z`，否则可能导致基础元素重叠，影响渲染。可以使用`Ctrl 右键`来快速挤出.

- 面模式下挤出：面模式下挤出会生成立方体：

  ![image-20260317000739920](https://raw.githubusercontent.com/LingxiReihi/PicGo/master/img/20260317000740090.png)

  ![image-20260317000833122](https://raw.githubusercontent.com/LingxiReihi/PicGo/master/img/20260317000833299.png)

+ 到首选点：合并到第一个选中的点。
+ 到末选点：合并到最后一个选中的点。
+ 按距离：将选中点符合距离要求的合并到一起。

修改器的优势：

+ 建模快，效率高，能快速直观的实现一个效果
+ 非破坏性，可以在不改变原来模型的基础啊上，精确的控制参数
+ 灵活，可以重复使用并叠加多个效果

修改的劣势：==使用修改器非常容易导致模型布线混乱==或出现其他多于线条或边。使用时需要**注意`Ctrl A`应用旋转及缩放**。

## 材质篇

材质是改变物体外观的重要元素，Blender中的材质需要有物体使用，或者添加了一个伪用户（材质旁边的小盾牌图标），否则==关闭Blender的时候会自动清理掉没有使用过的材质==。

### 原理化BSDF

#### 基础设置

| 名称   | 功能                                                         |
| ------ | ------------------------------------------------------------ |
| 基础色 | 修改物体表面显示的基础样式                                   |
| 金属度 | 模拟物体表面反射，为1则完全镜面反射（通常不会取中间值，而是直接0或1） |
| 糙度   | 设置物体表面光滑，当取值为0的时候光滑程度最高，配合1金属度可以实现类似于镜子的效果 |
|        |                                                              |



#### 高光

| 名称                        | 功能                                                         |
| --------------------------- | ------------------------------------------------------------ |
| 表面光散射分布：GGX         | 设置物体表面光散射                                           |
| 表面光散射分布：多重散射GGX | 对GGX的额外修正，相较于GGX更加真实，但性能消耗更高。         |
| 折射率（IOR）等级           | 物体表面的投射折射效果                                       |
| 染色                        | 对高光进行染色，当折射率/折射率等级越高效果越明显（会在物体表面附着一层对应颜色的高光） |

#### 次表面

| 名称                         | 功能                                                 |
| ---------------------------- | ---------------------------------------------------- |
| 次表面方法：克里斯坦森-伯利  | 基于物理的体积散射的近似值                           |
| 次表面方法：随机游走         | 使用指定散射半径，基于物理的体积散射                 |
| 次表面方法：随机游走（皮肤） | 基于体积散射，使用散射半径自动匹配颜色，用于皮肤渲染 |
|                              |                                                      |

#### 边缘光泽

| 名称 | 功能                                              |
| ---- | ------------------------------------------------- |
| 权重 | 设置表面高光的可见度，权重越低高光越淡            |
| 糙度 | 透过高光的光线反射 ，糙度越高表面对反射的影响越大 |
| 光泽 | 表面高光的颜色                                    |

| 糙度          | 设置涂层的反光程度                                           |
| 折射率（IOR） | 设置涂层的表面散射与折射                                     |

### 凹凸形变

制作具有形变的凹凸效果需要用到四张图片：

+ 基础纹理图：用于设置物体显示的主要颜色。
+ 糙度图Roughness：设置物体表面糙度值。
+ 法线贴图：设置物体表面的凹凸视觉效果。
+ 置换图Displacement：设置物体表面的置换形变效果。

制作凹凸形变的效果有两种，一种是使用置换修改器，将置换图设置为置换贴图，实现物体的凹凸效果，另一种则是通过材质进行设置，这种设置将只会在Cycles渲染下才能显示出效果。

使用材质制作凹凸效果需要打开材质中的设置启动置换与凹凸：<img src="https://raw.githubusercontent.com/LingxiReihi/PicGo/master/img/20260412214712340.png" alt="image-20260412214705240" style="zoom:50%;" />

通过添加置换节点将置换贴图设置到材质中，这种修改可以将形变控制在材质中，但是性能消耗很高，并且只能通过Cycles渲染：

## UV展开及贴图绘制

### 什么是UV

UV是3D模型表面对2D模型的映射，它用于告诉计算机3D模型表面渲染时对应2D图片的那个位置，以此来得到我们想要的效果。

而UV贴图则是一张普通的2D图片，渲染时会根据映射关系在这张图片上取出每个像素点对应的颜色并进行渲染。

### Blender打光工作流

- 对场景进行思考：场景出现在哪？
- 打世界定基调：判断场景所处位置，室内还是室外，哪一个时间点，是否使用HDRI贴图打光。
  - 打世界光的四种方法：修改默认背景节点、天空纹理、渐变纹理、环境纹理
- 布置场景光：让布光有主次、有逻辑、有美感。
  - 场景光四种光源：点光、日光、聚光、面光
  - 三点布光法：主光、辅助光、轮廓光
  - 打光要有的思考：主次分明、有逻辑、有美感

### 场景素材的导入

导入方式：`文件->关联/追加`。

优缺点比较：

| 方式 | 优点                                                         | 缺点                                   |
| ---- | :----------------------------------------------------------- | -------------------------------------- |
| 关联 | 1.节省资源，可以防止单个文件过大。<br>2.一个模型可以关联给多个场景。<br>3.修改原文件，所有场景自动替换。 | 无法直接修改，需要找到源文件           |
| 追加 | 可以直接修改模型。                                           | 添加模型过多导致场景文件大，占用资源。 |

#### 生成组

生成组修改器用于快速生成物体，可以按照设定对物体对象进行修改，具体包含的常用功能如下：

| 修改器名称 | 功能                                                         |
| ---------- | ------------------------------------------------------------ |
| 阵列       | 按照设置好的参数对模型将进行批量复制<br>（1）适配类型：可以简单设置生成数量及规律；<br>（2）相对偏移：下一个复制的物体相对于上一个物体的偏移位置；<br>（3）恒定偏移：每一个物体固定的偏移量，会与固定偏移做加法运算一起偏移；<br>（4）物体偏移：根据选中的一个物体来计算偏移量，适合制作一些特殊效果；<br>（5）合并：如果启用的话，在指定的距离内，每个副本中的顶点会和下一个副本中的顶点合并。 |
| 倒角       | 可以快速对物体所有边进行倒角，并且可以随时进行修改（在进行其他操作时需要应用修改）。 |
| 布尔       | 实现可修改的布尔效果。                                       |
| 建形       | 实现物体一点点出现的效果。                                   |
| 精简       | 可以减少模型面数，模型会不可避免发生形变。                   |
| 拆边       | 将模型每一条边进行拆分，成为单个独立的面。                   |
| 遮罩       | 将未选中的顶点进行隐藏，可以随时显示或取消显示，便于观察与修改。 |
| 镜像       | 生成镜像对象，并且可以对模型做镜像修改。                     |
| 多级精度   | 常用于雕刻模式下面数不够使增加面数进行雕刻。                 |
| 重构网格   | 根据选择的网格类型，对网格进行重构。                         |
| 螺旋       | 设置物体绕某一轴心对象将进行不同方式的旋转。                 |
| 蒙皮       | 根据点线生成物体对象，适合制作树枝等修长分叉物体，可以一键生成骨骼。 |
| 实体化     | 类似于挤出，可以为面快速增加厚度。                           |
| 表面细分   | 将面进行细分并平滑。                                         |
| 三角化     | 将各个面三角化，可以按照设置的参数将进行自定义三角化。       |
| 焊接       | 实现一定距离内的点自动焊接到一起。                           |
| 线框       | 将模型按照布线进行线框化，适合制作网格类似物。               |
