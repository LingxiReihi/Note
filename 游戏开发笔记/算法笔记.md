# 算法

## 二分查找

### 什么是二分查找

二分查找即在一段==有序==数据中找寻一个目标值`target`并返回对应下标的算法，他的时间复杂度为`O(log n)`。

### 二分查找有什么要求/什么情况下可以使用二分查找

+ 数据必须有序，不可以是无序数据或随机数据。
+ 只能查找一个目标值，不可以用于查找多个值。

### 如何使用二分查找

确定搜索区间：

+ 因为二分查找是通过每次取中止与`target`进行比较来确定的实际位置，所以在查找该值前需要有一个明确的区间查找定义，不同的定义对书写代码是的语句也会产生不同的影响。
+ 常用的区间有左闭右闭即`[left, right]`和左闭右开`[left,right)`，使用左闭右闭时需要注意`left = right`是一个有效区间，而左闭右开时`left = right`则是一个无效区间。
+ 对于开区间，边界值应不应是可能为实际结果的值，闭区间则可以是为实际结果的值。

确立搜索查找逻辑：

+ 在查找时，通常有三种情况，①中点值为我们所需值，直接返回下标；②中点值大于`target`，更新右边界；③中点值小于`target`，更新左边界。
+ 在更新边界值时，应该考虑对应的开闭区间，根据开闭区间进行边界更新。

### 代码示例

左闭右闭写法：

```c#
public int Search(int[] nums, int target)
{
    //确定初始值，左闭右闭即left和right都包含有目标值
    int left = 0, right = nums.Length - 1;
    //闭区间边界值可以相等
    while (left <= right)
    {
        //中点值应该为 左边界 + 左右边界区间的一半
        int middle = left + (right - left) / 2;
        //中点值为目标值时直接返回索引
        if (nums[middle] == target) return middle;
        //中点值大于目标值更新右索引，闭区间可以包括目标值索引，确定值为middle-1，避免重复比较nums[middle]
        else if (nums[middle] > target) right = middle - 1;
        //小于目标值则更新左边界
        else left = middle + 1;
    }
    //查找完成没有货的目标值则返回-1
    return -1;
}
```

左闭右开写法：

```c#
public int Search(int[] nums, int target)
{
    //有边界为开区间，不应包含可能为目标值的末尾值，所以设置为nums.Length
    int left = 0, right = nums.Length;
    //左右边界不可能相等
    while (left < right)
    {
        int middle = left + (right - left) / 2;
        if (nums[middle] == target) return middle;
        //有边界不能包含可能值，所以直接更新为middle
        else if (nums[middle] > target) right = middle;
        else left = middle + 1;
    }
    return -1;
}
```
